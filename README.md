# Digital Lending Credit Risk Analysis with SQL

A simulated digital lending dataset designed for practicing SQL for business analysis and credit risk strategy.

## Dataset

- 500 customers
- 1,500 loans
- Repayment records for completed/partial payments
- 3,000 customer transactions
- Markets: Kenya, Nigeria, Ghana, Uganda

## Purpose

This is a synthetic dataset. It is not real customer or company data.

The project is designed to practice:
- JOINs
- GROUP BY / HAVING
- CASE WHEN
- CTEs and subqueries
- Window functions
- RANK / ROW_NUMBER
- LAG
- Date-based analysis
- Credit-risk business analysis
